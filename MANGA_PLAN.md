# Манга-конвейер — план на будущее

Идея: делать страницы манги/комикса — **те же персонажи** в **том же сеттинге**
выполняют **разные действия** по панелям. Документ — дорожная карта, не готовый
пайплайн. Накоплено из отладки Unblend (точки, Sequential Refine, Assign Masks).

---

## Ключевые принципы (что усвоили на практике)

1. **Денойз меняет наполнение, не действие.** Один глобальный ползунок «хранить
   ↔ менять» не умеет «поменяй позу, сохрани фон и лица».
2. **Действие = структура → задаётся позой (ControlNet), а не img2img.** img2img
   полирует, не хореографит.
3. **Маска решает, ЧТО сохранить.** Тесный силуэт (Sequential Refine) запирает
   позу; щедрая зона + поза-ControlNet — позволяет позу сменить.
4. **Sequential Refine = «что под маской меняем, что вне — храним».** Это и есть
   рычаг «сохрани фон/соседа, перерисуй персонажа».

---

## Архитектура одной панели (слои)

| Слой | Чем делается | Статус в Unblend |
|---|---|---|
| **Действие** (поза панели) | OpenPose-скелет → ControlNet | ✅ **Pose Engine** отдаёт OpenPose |
| **Фон** (тот же) | фон-пластина (пустая комната) + inpaint | ⛔ внешний (пластину готовить вручную) |
| **Личности** (те же) | канон-теги + character-LoRA / IPAdapter / reference | ⛔ внешний слой |
| **Разделение 2+ персонажей** | Dynamic → SAM → Assign → Sequential Refine | ✅ есть |
| **Полировка** (детали/цвета) | Sequential Refine (масочный img2img) | ✅ есть |
| **Сборка панелей в страницу** | раскладка/композ | ⛔ нет (вручную/внешне) |

---

## Что уже есть в Unblend (можно опереться)

- **Unblend Dynamic Sampler** — разделение 2+ персонажей в одной панели
  (точки `char_points`, `identity_lock`, `early_jail`).
- **Unblend SAM2 / Deepghs Char Seg** — инстанс-маски (геометрия, окклюзия).
- **Unblend Assign Masks** — размечает инстанс-маски по точкам (личность).
- **Unblend Sequential Refine** — чистая детализация персонажа без утечки.
- **Unblend Pose Engine** — OpenPose-картинка для ControlNet (**автор действия**).
- **Unblend Line Counter** + CSV/Execute Python — конвейер «файл строк → поток
  артов» (готовая основа под панели).

---

## Чего не хватает (честно — это hard parts)

1. **Консистентность персонажей между панелями — главная боль.**
   Канон-теги + фиксированный seed держат лицо лишь частично; при смене позы
   аниме-модели дрейфуют. Надёжно — только референсом:
   - **character-LoRA** на каждого персонажа (самое стабильное на Illustrious);
   - **IPAdapter** с лица/референса панели-1;
   - reference-only ControlNet.
   Без этого — «похожие, но не те же».
2. **Идентичный фон.** Для пиксель-в-пиксель: сгенерить **фон-пластину один раз**
   (пустая комната) и инпейнтить персонажей поверх. Для «того же сеттинга» (не
   пиксельно) хватит одинаковых тегов `[SCENE]`.
3. **Действие — структурное изменение.** Нужен поза-ControlNet + щедрая
   инпейнт-зона + высокий денойз в ней; тесный силуэт позу не сменит.

## Дорожная карта (фазы)

### Фаза 1 — proof: одна смена действия
Собрать панель: **фон-пластина + поза-ControlNet (Pose Engine) + Sequential
Refine**. Цель — убедиться, что «тот же фон/герои, новое действие» вообще
складывается на одной паре кадров.

### Фаза 2 — `[INTERACTn]` через готовый счётчик
`interactions.csv` (по строке на панель: действие + опц. поза/камера). Общий
префикс `[QUALITY]/[STYLE]/[SCENE]/[CHARn]` фиксирован. **Line Counter** гоняет
строки → каждый прогон = панель. Почти без кода — переиспользуем конвейер.

### Фаза 3 — нода `Unblend Panel Sequence`
Вход: общий промпт + список действий (+ опц. позы). Выход: батч картинок-панелей.
Внутри гоняет пайплайн Dynamic → Assign → Sequential Refine по каждой строке.

### Фаза 4 — консистентность + сборка страницы
- character-LoRA / IPAdapter как обязательный слой личности между панелями;
- единая seed-стратегия;
- раскладка панелей в страницу (внешняя нода/композ).

---

## Формат `[INTERACTn]` (черновик)

Вариант A — **внешний CSV** (Фаза 2):
```
panel, interact, pose, camera
1, "sitting embrace, cheek to cheek", pose1.png, "eye level"
2, "fischl pulls columbina closer, surprised", pose2.png, "low angle"
3, "both reading a book together, calm", pose3.png, "eye level"
```

Вариант B — **много тегов в одном промпте** (Фаза 3, нода сама итерирует):
```
[INTERACT1] sitting embrace, cheek to cheek
[INTERACT2] fischl pulls columbina closer, surprised
[INTERACT3] both reading a book together, calm
```
